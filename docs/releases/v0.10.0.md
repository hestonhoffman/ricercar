**ricercar 0.10.0** lets you browse your library by composer, helps you set up your audio output on first launch, and highlights synced lyrics word by word.

## Downloads

| Your system | File | Install |
|---|---|---|
| Debian 12+, Ubuntu 22.04+, Mint, Pop!_OS, Zorin, elementary | `ricercar_0.10.0-1_amd64.deb` / `_arm64.deb` | `sudo apt install ./ricercar_*.deb` |
| Fedora, openSUSE Tumbleweed / Leap 16, RHEL / Alma / Rocky 10+ | `ricercar-0.10.0-1.x86_64.rpm` / `.aarch64.rpm` | `sudo dnf install ./ricercar-*.rpm` (`zypper install` on openSUSE) |
| Arch, Manjaro, EndeavourOS, CachyOS, Omarchy | `ricercar-0.10.0-1-x86_64.pkg.tar.zst` | `sudo pacman -U ricercar-*.pkg.tar.zst` |
| Any distribution (portable) | `ricercar-0.10.0-x86_64.AppImage` / `-aarch64.AppImage` | `chmod +x ricercar-*.AppImage && ./ricercar-*.AppImage` |
| Any distribution (plain binaries) | `ricercar-0.10.0-linux-x86_64.tar.gz` / `-aarch64` | unpack, run `bin/ricercar` |

sha256sum --check --ignore-missing SHA256SUMS

## What's new

- **Composers.** A Composers page in the sidebar lists everyone found in the COMPOSER tag of your files. A composer's page shows their albums and their works, grouped by album, with Play, Shuffle and Add to queue. A track's menu has *Go to composer*, and search shows matching composers. UPnP control points also get a Composers folder.
- **Audio setup on first launch.** A short assistant lets you pick the interface language, then an output (hardware `hw:` outputs first, named by their card), shows what your DAC plays natively, and offers fixed volume. *Later* skips it at any step. It does not appear if you already chose an output, and Settings → Audio output opens it again.
- **Word-by-word lyrics.** When synced lyrics time each word (enhanced LRC, `<mm:ss.xx>` inside a line), the current line lights up word by word. Line-by-line lyrics work as before; *Estimate word timing* in Settings → Appearance (off by default) lights up their words at an estimated pace.
- **Fixes.**
  - Long sign-in addresses no longer push the plugin sign-in dialog off screen.
  - A few interface strings (the search scopes, *System*) now show translated.

## For plugin authors

- `lyrics.get`: a synced line may carry an optional `words` list (`{"time_ms": …, "text": "…"}`). Older versions ignore it. See `docs/plugins.md`.

> From 0.6.0 or later, *Update now* in Settings → About installs this version, checked against the signed `SHA256SUMS`.

> Plugins are written by third parties and are not reviewed by the ricercar project. They run with your permissions: install only plugins you trust, and check that they respect the terms of the service they use.

**From source:** `cargo build --release` with Rust 1.92 or newer (see the README for per-distro dependencies).
